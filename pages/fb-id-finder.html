របៀប Get App ID + Secret:
1. ចូល developers.facebook.com/apps → Login
2. Create App → ជ្រើស "Other" → "Business"
3. App Dashboard → Settings → Basic → Copy App ID + App Secret
4. Paste ខាងលើ → រក្សាទុក → ស្វែងរក ID ដោយ automatic
